# dustsweeper 탐색기 설계

이 문서는 2026-11-17에 승인된 탐색기 설계다.
1차 `scan`, 2차 `inspect`, 3차 `narrate`의 JSON 계약은 `docs/specs/2026-11-16-dustsweeper-design.md`에 있다.
그 문서의 인자 없음 규칙은 이 문서가 대체한다.

탐색기는 용량을 한 디렉터리씩 보게 한다.
파일을 지우거나 옮기거나 이름을 바꾸지 않는다.
파일 내용은 읽지 않는다.

## 하지 않는 일

- `rm`, `unlink`, 영구 삭제, 이름 변경, 끌어다 놓기
- 휴지통 이동은 `docs/specs/2026-11-17-trash-design.md`만 허용한다.
- 후보 파일의 내용 읽기
- 선택 행의 정체, 열린 파일, 최근 사용일, 서술
- 마우스, 색 테마, 새 패키지
- `scan`의 `-d`, `-P`, 후보 선택, JSON 키 변경
- 여러 루트, Linux, Windows, GUI

## 명령

인자가 없으면 현재 디렉터리의 탐색기다.
`dustsweeper browse`도 현재 디렉터리다.
`dustsweeper browse --root PATH`는 그 경로 하나다.
`--root`가 둘이면 종료 코드 2이고, 표준에러는 사용법 한 줄이다.

알 수 없는 인자, 값 없는 옵션, `delete`, `rm`은 종료 코드 2다.
표준에러는 다음 한 줄과 끝의 개행 하나다. 파서의 기본 오류문은 쓰지 않는다.

`usage: dustsweeper {browse|scan|inspect|narrate}`

`scan`, `inspect`, `narrate`의 인자와 JSON은 바뀌지 않는다.

종료 코드는 성공 `0`, 사용법·입력·측정 실패 `2`뿐이다.

표준입력과 표준출력 중 하나라도 터미널이 아니면 `dust`를 실행하지 않는다.
표준에러는 `browse requires a terminal`과 끝의 개행 하나다.
표준출력의 높이가 4줄보다 작으면 `dust`를 실행하지 않는다.
표준에러는 `terminal too small`과 끝의 개행 하나다.
이 두 검사는 `browse`와 인자 없음에만 적용된다.

## 측정

탐색기 인자 순서는 이 목록 그대로다.

`dust -j -o b -- <root>`

`-d`, `-P`, `-n`은 붙이지 않는다.
표준출력은 중첩 JSON이다. 디스크에 JSON 파일이 생겼는지 찾지 않는다.
표준에러는 측정 중에 터미널로 그대로 보낸다.
종료 코드가 0이면 표준출력을 트리로 읽고 원문 문자열은 버린다.
그 트리 안에서만 이동한다. 들어갈 때 `dust`를 다시 실행하지 않는다.

`dust`가 없으면 표준에러는 `dust not found`와 끝의 개행 하나다.
종료 코드가 0이 아니고 표준에러가 비어 있으면 `dust failed`와 끝의 개행 하나다.
표준에러가 있으면 그 출력이 이미 보이므로 같은 문장을 다시 쓰지 않는다.
JSON이 아니면 `dust json is invalid`와 끝의 개행 하나다.
크기가 `^[0-9]+B$`가 아니면 `dust size is not bytes: <원문>`과 끝의 개행 하나다.
이 실패에서는 화면을 열지 않는다.

경로는 1차와 같다.
`name`이 `.`이면 루트다.
`./keep`은 `<root>/keep`다.
`/`로 시작하면 그 절대 경로를 쓴다.
끝의 `/`는 루트 `/`가 아니면 제거한다.

## 화면

맨 위 줄은 현재 노드의 경로다.
다음 줄은 열 이름 `이름`, `크기`, `비율`이다.
맨 아래 줄은 선택한 행의 크기와 비율이다.
선택한 행이 없으면 맨 아래 줄은 비어 있다.
가운데 줄만 항목이다.

항목은 현재 디렉터리의 자식만 보여 준다.
정렬은 `(-size_bytes, path)`다.
같은 크기면 경로 오름차순으로 먼저다.
이름 열은 경로의 마지막 성분이다.
크기 열은 10칸, 오른쪽 정렬이다. 표시가 10칸을 넘으면 그 칸만 늘린다.
비율 열은 4칸, 오른쪽 정렬이고 `89%`처럼 적는다.
열 사이는 공백 두 칸이다.
열 이름 줄도 같은 칸 폭을 쓴다.
선택한 행은 반전 표시다.
색은 쓰지 않는다.

화면 높이가 4줄이면 항목 칸은 1칸이다.
항목 칸이 자식 수 이상이면 자식을 모두 보여 주고 `나머지` 줄은 없다.
항목 칸이 2칸 이상이고 자식이 더 많으면 마지막 칸은 `나머지` 줄이다.
보여주는 자식 수는 항목 칸에서 1을 뺀 값이다.
항목 칸이 1칸이고 자식이 2개 이상이면 가장 큰 자식 하나만 보여 준다.
이 경우에는 `나머지` 줄이 없다.

`나머지` 줄의 이름은 `나머지 N개`다.
`N`은 보여 주지 않은 자식 수다.
크기는 그 자식들의 `size_bytes` 합이다.
부모 크기에서 보여 준 크기를 빼서 만들지 않는다.
이 줄에는 `/`를 붙이지 않는다.
Enter는 아무 일도 하지 않는다.

비율의 분모는 현재 노드의 `size_bytes`다.
자식 크기의 합이 아니다.
분자에 100을 곱하고 분모의 절반을 더한 뒤 분모로 나눈 정수다.
분모가 0이면 0이다.
따라서 표시된 비율의 합이 100이 아닐 수 있다.

크기는 1024 단위다.
단위는 `B`, `KiB`, `MiB`, `GiB`, `TiB`다.
1 이상인 가장 큰 단위를 쓴다.
`TiB`보다 큰 단위는 없다.
1024 미만은 정수와 `B`다.
그 외에는 소수 한 자리를 보인 뒤 `.0`을 뺀다.
`61762732032`는 `57.5GiB`다.
`1536`은 `1.5KiB`다.
`1024`는 `1KiB`다.

표시 폭은 `unicodedata.east_asian_width`로 센다.
`W`와 `F`는 2, 그 외는 1이다.
경로 줄이 폭을 넘으면 끝부분을 남기고 앞에 `...`를 붙인다.
이름 열이 폭을 넘으면 끝부분을 자르고 뒤에 `...`를 붙인다.
잘린 결과의 표시 폭은 허용 폭 이하다.

디렉터리 표시는 화면에 나온 항목만 `stat`한다.
디렉터리면 이름 끝에 `/`를 붙인다.
`stat`이 실패하거나 파일이면 `/`가 없다.
`children: []`만으로 디렉터리라고 보지 않는다.
빈 디렉터리와 파일이 그 값을 같이 쓰기 때문이다.
전체 트리를 미리 `stat`하지 않는다.

창 크기가 바뀌면 보이는 줄을 다시 계산하고, 선택 위치는 마지막 보이는 줄 안으로 당긴다.

## 키

위와 아래만 선택을 옮긴다.
맨 위와 맨 아래를 넘기지 않는다.
Enter의 디렉터리 여부는 `tui.py`가 넘긴다. `tree.py`는 `stat`하지 않는다.
그 값이 참일 때만 자식 목록으로 들어간다.
들어가면 선택 위치는 0이다.
파일, `나머지` 줄, `stat` 실패에서는 아무 일도 하지 않는다.
Backspace와 왼쪽 방향키는 들어온 스택을 하나 올린다.
루트에서는 아무 일도 하지 않는다.
q와 화면 안의 Ctrl-C는 종료 코드 0이다.
측정 중 Ctrl-C는 종료 코드 2다.
그 외의 키는 무시한다. `d`와 확인은 `docs/specs/2026-11-17-trash-design.md`가 정한다.

## 파일 책임

| 파일 | 책임 |
|---|---|
| `src/dustsweeper/tree.py` | 탐색기용 `dust` 인자, 트리 파싱, 크기 문자열, 비율, 보이는 줄, 키 상태 |
| `src/dustsweeper/tui.py` | 터미널 확인, `dust` 실행, 보이는 줄의 `stat`, `curses` 그리기 |
| `src/dustsweeper/cli.py` | 인자 없음과 `browse`를 탐색기로 연결 |
| `tests/test_tree.py` | 트리, 줄, 비율, 크기 문자열, 키 상태 |
| `tests/test_cli.py` | 인자 없음이 터미널이 아니면 2인지 확인 |
| `README.md` | 탐색기를 여는 방법 |

`scan.py`는 수정하지 않는다.
`tree.py`는 `curses`를 가져오지 않는다.
`tui.py`는 후보 선택과 JSON 리포트를 만들지 않는다.

키 상태는 `stack`과 `selected`다.
`stack`의 첫 원소는 루트고, 마지막 원소가 현재 노드다.
보이는 줄의 종류는 `entry` 또는 `rest`다.
`rest`의 경로는 없다.

## 검증

테스트는 `curses` 없이 `tree.py`의 순수 함수를 호출한다.
중첩 JSON에서 부모와 자식 경로가 맞아야 한다.
지정한 높이에 대해 보이는 자식 수와 `나머지`의 개수, 크기 합이 맞아야 한다.
비율의 분모는 현재 노드의 크기다.
`61762732032`는 `57.5GiB`다.
Enter는 디렉터리만 스택에 넣는다.
파일과 `나머지`와 루트의 Backspace는 상태를 바꾸지 않는다.
인자 없음이고 표준입력 또는 표준출력이 터미널이 아니면 종료 코드 2, 표준에러 `browse requires a terminal`과 끝의 개행 하나다.
`delete`와 `rm`은 계속 2다.
`scan`의 기존 테스트는 유지한다.
소스와 README에 `os.remove`, `os.unlink`, `shutil.rmtree`, `send2trash`를 두지 않는다.
