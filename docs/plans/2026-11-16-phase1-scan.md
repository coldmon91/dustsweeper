# 1차 scan 구현 계획

> **For agentic workers:** Implement this plan task-by-task, in order. Steps use checkbox (`- [ ]`) syntax for tracking — mark each one done as you finish it.

**Goal:** `dust` 측정값을 크기 기준 후보 JSON으로 내고, 삭제 명령은 만들지 않는다.

**Architecture:** `dust -j -o b`의 표준출력을 파싱하고, 깊이 0과 최소 크기 미만을 버린 뒤 큰 순서로 `limit`개만 남긴다. 증거·규칙·서술은 이 계획에 없다.

**Tech Stack:** Python >=3.12, uv 0.10.12, ruff, ty, pytest. 검증은 `uv run pytest`와 `uv run dustsweeper`다.

**Spec:** `docs/specs/2026-11-16-dustsweeper-design.md`

## Global Constraints

- 플랫폼은 macOS다. 관측한 `dust`는 1.2.6, `lsof`는 4.91이다.
- Dust 1.2.6의 `-j` 도움말은 "current directory"라고 적혀 있다. 관측 결과는 표준출력 JSON이고 표준에러는 비어 있다. 구현은 표준출력을 읽고, 디스크에 JSON 파일이 생겼는지 찾지 않는다.
- 크기 출력은 `-o b`일 때 `208896B`처럼 숫자와 접미사 `B`다. `4.0Ki` 같은 값은 오류다.
- 기본값: `min_bytes` `1073741824`, `depth` `2`, `limit` `50`, report `version` `1`.
- Python `>=3.12`. 패키지 이름은 `dustsweeper`. 의존성 추가는 `uv add`만 쓴다.
- `touch`는 `report_only`, `live`, `reinstallable`, `unknown` 중 하나다. 어느 값도 삭제 허가가 아니다. 1차 리포트에는 `touch` 키를 넣지 않는다.
- 열린 파일은 후보 경로와 같거나 그 하위일 때만 해당한다. 1차는 열린 파일을 조회하지 않는다.
- 앱 최근 사용일과 데몬 실행은 별개 필드다. 1차는 둘 다 조회하지 않는다.
- `/Users/cskim/Documents/rsupport`로 끝나는 경로와 그 하위는 사용자 데이터다. 1차는 내용을 읽지 않고 경로와 크기만 후보로 낼 수 있다.
- 소스, README, 프롬프트에 `os.remove`, `os.unlink`, `shutil.rmtree`, `send2trash`를 두지 않는다. 테스트가 이 문자열을 금지 바늘로 갖는 것은 허용한다.
- `git init`과 브랜치 생성은 하지 않는다.

## 파일 지도

- `pyproject.toml`: 패키지 메타와 도구 설정. 스크립트 진입점은 `dustsweeper.cli:main`.
- `src/dustsweeper/model.py`: 상수와 `Node`, `Candidate`, `ScanError`.
- `src/dustsweeper/scan.py`: dust 인자, 크기 파싱, JSON 파싱, 후보 선택.
- `src/dustsweeper/report.py`: 1차 JSON 직렬화.
- `src/dustsweeper/cli.py`: `scan` 인자와 종료 코드.
- `tests/test_scan.py`, `tests/test_cli.py`: 아래 단언.
- `tests/fixtures/dust-bytes.json`, `tests/fixtures/dust-human.json`: 파서 입력.
- `README.md`: `scan` 사용법만.

cookiecutter는 쓰지 않는다. 디렉터리에 `AGENTS.md`와 `session-records/`가 이미 있다.

### Task 2: dust JSON 파싱과 후보 선택

**Files:**
- Create: `src/dustsweeper/model.py`
- Create: `src/dustsweeper/scan.py`
- Create: `tests/test_scan.py`
- Create: `tests/fixtures/dust-bytes.json`
- Create: `tests/fixtures/dust-human.json`

**Interfaces:**
- Consumes: 없음
- Produces: `MIN_BYTES_DEFAULT = 1073741824`, `DEPTH_DEFAULT = 2`, `CANDIDATE_LIMIT_DEFAULT = 50`, `REPORT_VERSION = 1`
- Produces: `class ScanError(Exception)`
- Produces: `Node(path: str, size_bytes: int, depth: int)`, `Candidate(path: str, size_bytes: int, depth: int)` 둘 다 frozen dataclass
- Produces: `dust_argv(binary: str, root: str, depth: int) -> list[str]`
- Produces: `parse_size_bytes(size: str) -> int`
- Produces: `parse_dust_json(raw: str, root: str) -> tuple[Node, ...]`
- Produces: `select_candidates(nodes: tuple[Node, ...], min_bytes: int, limit: int) -> tuple[Candidate, ...]`
- Produces: `scan_roots(roots: tuple[str, ...], depth: int, min_bytes: int, limit: int, runner: Callable[[list[str]], str], binary: str = "dust") -> tuple[Candidate, ...]`

- [x] **Step 1: State the invariants and test assertions**

**Invariants:** `dust_argv`는 `["<binary>", "-j", "-o", "b", "-P", "-d", "<depth>", "--", "<root>"]`다. `-n`, `-z`, `-x`는 없다. 크기는 `^[0-9]+B$`만 받는다. 후보 정렬 키는 `(-size_bytes, path)`다. 깊이 0은 후보가 아니다. `runner`가 받은 인자만으로 명령을 설명하고, 함수는 파일을 지우지 않는다.

**Test assertions:** `tests/test_scan.py`

```python
def test_dust_argv_is_byte_json_on_stdout():
    assert dust_argv("dust", "/tmp/scan", 1) == [
        "dust", "-j", "-o", "b", "-P", "-d", "1", "--", "/tmp/scan"
    ]

def test_parse_size_bytes_accepts_only_byte_suffix():
    assert parse_size_bytes("208896B") == 208896
    with pytest.raises(ScanError, match="dust size is not bytes: 4.0Ki"):
        parse_size_bytes("4.0Ki")

def test_parse_dust_json_joins_relative_names():
    raw = Path("tests/fixtures/dust-bytes.json").read_text()
    nodes = parse_dust_json(raw, "/tmp/scan")
    assert Node(path="/tmp/scan", size_bytes=208896, depth=0) in nodes
    assert Node(path="/tmp/scan/keep", size_bytes=204800, depth=1) in nodes
    assert Node(path="/tmp/scan/drop.bin", size_bytes=4096, depth=1) in nodes

def test_select_drops_root_and_small_files():
    nodes = (
        Node(path="/tmp/scan", size_bytes=208896, depth=0),
        Node(path="/tmp/scan/keep", size_bytes=204800, depth=1),
        Node(path="/tmp/scan/drop.bin", size_bytes=4096, depth=1),
    )
    assert select_candidates(nodes, min_bytes=100000, limit=50) == (
        Candidate(path="/tmp/scan/keep", size_bytes=204800, depth=1),
    )

def test_select_breaks_ties_by_path():
    nodes = (
        Node(path="/tmp/scan/b", size_bytes=100, depth=1),
        Node(path="/tmp/scan/a", size_bytes=100, depth=1),
    )
    selected = select_candidates(nodes, min_bytes=1, limit=1)
    assert selected == (Candidate(path="/tmp/scan/a", size_bytes=100, depth=1),)

def test_scan_roots_records_argv_and_applies_limit_once():
    seen = []

    def runner(argv):
        seen.append(argv)
        if argv[-1] == "/tmp/big":
            return '{"size":"300B","name":".","children":[{"size":"300B","name":"./big","children":[]}]}'
        return '{"size":"100B","name":".","children":[{"size":"100B","name":"./small","children":[]}]}'

    selected = scan_roots(("/tmp/small", "/tmp/big"), 1, 1, 1, runner)
    assert seen[0] == ["dust", "-j", "-o", "b", "-P", "-d", "1", "--", "/tmp/small"]
    assert selected == (Candidate(path="/tmp/big/big", size_bytes=300, depth=1),)
```


```python
def test_scan_fixture_stdout(capsys):
    code = main([
        "scan", "--dust-json", "tests/fixtures/dust-bytes.json",
        "--root", "/tmp/scan", "--min-bytes", "100000", "--limit", "50", "--depth", "1",
    ])
    assert code == 0
    assert capsys.readouterr().out == """{
  "candidates": [
    {
      "depth": 1,
      "path": "/tmp/scan/keep",
      "size_bytes": 204800
    }
  ],
  "min_bytes": 100000,
  "version": 1

def test_human_size_is_usage_error(capsys):
    code = main([
        "scan", "--dust-json", "tests/fixtures/dust-human.json",
        "--root", "/tmp/scan", "--min-bytes", "1", "--depth", "1",
    ])
    assert code == 2
    captured = capsys.readouterr()
    assert captured.out == ""
    assert captured.err == "dust size is not bytes: 4.0Ki\n"

def test_dust_json_rejects_two_roots(capsys):
    code = main([
        "scan", "--dust-json", "tests/fixtures/dust-bytes.json",
        "--root", "/tmp/a", "--root", "/tmp/b",
    ])
    assert code == 2
    assert capsys.readouterr().err == "dust-json requires exactly one root\n"

def test_negative_min_bytes(capsys):
    code = main(["scan", "--root", "/tmp/scan", "--min-bytes", "-1"])
    assert code == 2
    assert capsys.readouterr().err == "min_bytes must be >= 0\n"

def test_negative_depth(capsys):
    code = main(["scan", "--root", "/tmp/scan", "--depth", "-1"])
    assert code == 2
    assert capsys.readouterr().err == "depth must be >= 0\n"

def test_src_has_no_delete_api():
    text = "\n".join(path.read_text() for path in Path("src").rglob("*.py"))
    for token in ("os.remove", "os.unlink", "shutil.rmtree", "send2trash"):
        assert token not in text
```
